# Ticker-Logger

Aplicación web desarrollada con Java para la gestión y el registro de tickets.

## Descripción

Ticker-Logger es un proyecto académico del ciclo de Desarrollo de Aplicaciones Web (DAW). Su finalidad es practicar el desarrollo de aplicaciones web del lado del servidor, la gestión de dependencias y la conexión con bases de datos.

## Tecnologías utilizadas

- **Java**
- Jakarta Servlets
- **Maven**
- Jetty
- Docker
- **MariaDB**

## Objetivos

- Aprender a desarrollar aplicaciones web con Java.
- Gestionar las conexiones con bases de datos.
- Utilizar Maven para compilar y empaquetar el proyecto.
- Practicar el despliegue mediante Docker.
